## DeepSeek++ 1.16.0

1.16.0 是安全边界与稳定性收口版本：外部来源的 Skill 内容改为按不可信数据隔离，同步凭据不再明文落盘，第三方原生宿主加字节闸门，自动化排期与后台唤醒的竞态逐条闭合。本说明覆盖自上一份发布说明（1.14.0）以来在本仓库落地的全部变更；仓库内没有 1.15.x 的版本痕迹，快照进入时 `package.json` 已是 1.16.0。

### 安全边界

- **导入 Skill 正文隔离**：GitHub 与本地导入的 SKILL.md 正文一律包进不可信内容边界块，块内附「正文是数据不是指令」的语言跟随界面的提示；用户输入与本应用自身的指令段落在块外。
- **SKILL.md 解析单一真源**：两份各自演化的 `parseSkillDoc` 合并为 `core/skill/parse-skill-doc.ts`，两个导入器只绑定各自的 profile，杜绝「加固只改一处、另一处仍可绕过」。
- **导入描述中性化**：远端 frontmatter 与导入生成的 Skill 描述在进入模型上下文前先中性化，注入文本不再直达指令层。
- **同步凭据不落盘**：同步凭据改存 `chrome.storage.session`，浏览器重启即失效；盘上残留的公开值只允许「重新授权」这一条恢复路径。
- **本地 Skill 根目录逃逸拦截**：本地 Skill 目录的符号链接越界读取被拒绝。
- **第三方原生宿主字节闸门**：出站信封受 1 MB 上限，请求与通知走同一条端口、同一个闸门；`local_file_write` 的正文另有 900 KB 上限；超限抛错并提示分段，不再静默截断。第一方多模态宿主豁免该闸门（图像/视频由宿主自行交给模型，回归已钉住）。
- **页面侧留存收紧**：被劫持的控制台日志不再写入页面可读存储；调试遥测面板只保留数值并受侧栏闸控。
- **工具调用原文不再泄漏进页面**：提示增强失败回退时，原始工具调用 XML 仍会被过滤，不再以裸标签形式出现在可读回复里。

### 自动化与后台

- **cron 求解器重写**：修复跨月/步进/星期域的错误解算，夏令时缺失的墙上时间落到过渡后的那一分钟；排期算不出下一跳时任务转 `paused` 终态并写明错误，不再让 1 分钟唤醒无限重算。
- **删除即终态**：删除自动化前，`queued/running` 行先原子写成终态；外部结果未知的运行记为 `ambiguous`，不伪装成「确定没发生」。
- **唤醒闹钟只在缺失时创建**，避免每次唤醒重写闹钟。
- **每笔持久化的工具记录受 prompt 预算约束**；工具历史首条追加在无历史键的配置上不再被丢弃，且写入前按 `QUOTA_BYTES` 主动裁剪最旧记录。
- **取消语义与到期任务并发**两条未在本轮改动，已各留一张决策单待裁。

### 远程控制与工具链

- **重发要有回执**：手机侧重发的消息只有在本地历史里可见之后才推进读取游标，避免「回车没生效但游标照样前推」的静默丢消息。
- **落后宿主可见**：第一方原生宿主版本落后于插件时给出机器可读码与界面提示，不再显示成健康。
- **记忆工具的写入会回传模型**：`memory_save` / `memory_update` / `memory_delete` 执行成功后进入可续跑集，最终回复不再因为缺一次回传而整条丢失。
- **发送读的是当前输入框**：点击发送按钮时取的是插件自己维护的合成输入框内容，回退路径改为驱动 contenteditable，不再依赖 textarea 的 setter（那在 contenteditable 界面上是空写）。
- **瞬时后台失败不再一刀切禁用工具**：描述符契约错误与非契约错误分道，MV3 唤醒竞态下保留上一份已知目录。
- **官方 API 无人管理的流带截止时间**；授权墓碑会过期；合并写入队列被清空抢先时返回类型化 `burst_superseded` 而不是静默空对象；侧栏最新一次配置保存独占状态。

### 存储与导出

- 每个项目保留的会话数封顶 200。
- 会话全量导出按存储的上限档位截断（默认 500）并在界面明说，不悄悄少给。

### 质量闸与发布资产

- 中文注释不再被算作未国际化命中（判据收窄到字符串字面量，解析失败即红）。
- 新增测试收编完整性闸；逐条超时预算改为带实测理由的声明。
- Shell Host 安装态布局检查可在 Windows 上运行；版本三元组（插件、宿主、锁文件）重新对齐 1.16.0。
- 发布资产校验改用无依赖的 ZIP 读取器，不再依赖 Windows 上没有的 `unzip`。
- **权限变化**：自快照以来的改动未新增浏览器权限。
